# AI Declaration

This project used AI tools as development support during the creation of **Rift Protocol**.

## AI Tools Used

AI assistance was used through ChatGPT / Codex during development.

## How AI Was Used

AI was used to support the following tasks:

- Explaining Unity concepts.
- Helping debug during development.
- Generating or improving scripts.
- Helping organize and refine testing documentation.
- Helping write project documentation.
- Generating some assets.


All AI-assisted work was reviewed, selected, edited, integrated, and tested by me.
AI was used as a support tool, not as a replacement for understanding or developing the project.

## AI-Generated Assets

The following project assets were generated with AI:

- Background and UI images in `Assets/Art/Background`.
- `respawn1.wav` player respawn sound effect.

These assets were integrated manually into the game.
